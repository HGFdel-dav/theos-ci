# TIMCleanKit 1.0.9

目标 TIM 4.1.0.81（com.tencent.tim），iOS 15.0+；SDK 15.5，Theos/Logos，arm64 + arm64e。

## 1.0.9 变化（本轮）

- **复读改为单击**：单击任意消息气泡立即向原会话重发一次（原双击对 TIM 4.1.0 失效：其 cell 绑定不走 bindViewModel:/setViewModel:，改为布局时直接遍历实例 ivar 取 viewModel/record，不再依赖绑定回调）。
- **红包逻辑简化**：删除"未知金额放行"开关。领取前金额未知（随机红包）一律不抢；已知金额只按"最低~最高"区间判断（0 表示不设限），测试/外挂/体验关键词跳过保持不变。
- 其余保留 1.0.8：标签贴气泡尾、弹窗尺寸固定、不透明输入面板、UI 简洁化。

## 1.0.5 变化（上轮）

- 设置改为中央磨砂玻璃弹窗：系统材质模糊、半透明圆角面板、柔和边框与阴影，深浅色适配。点弹窗外或右上角"完成"收起；关键词与诊断在同一弹窗内切换。开启系统"降低透明度"时使用可读的实色背景。
- 设置入口只保留全区域双指长按 0.8 秒。聊天内容和控件区域均可唤醒；关闭插件总开关仍可打开设置。移除单指空白点击。
- 红包最低/最高金额可自行输入人民币元，最多两位小数，包含两端。最低 0 表示不设下限，最高 0 表示不设上限。保存精确整数分，拒绝负数、无效数字和最高低于最低。
- 新增“未知金额放行”。**随机红包领取前通常不知道实际到账金额**。开启时未知金额仍自动领取；关闭时跳过未知金额，多数随机红包将不会抢。已知金额文案也不保证就是个人实际到账金额。
- 红包关键词默认“测试、外挂、体验”，可以自行增删。标题、内容或名称命中任一关键词即跳过，英文不区分大小写；支持中文逗号、逗号、空格、换行。清空表示不匹配关键词。保持红包气泡显示，不隐藏被过滤红包。
- 防撤回接入 SWIKernelMsgListener 的真实接收、撤回、更新和删除桥接。缓存本次进程最近 500 条收到/显示的消息，按会话与消息序号匹配，尝试保留原记录并在气泡旁显示“拦截撤回”。
- 双击实际消息气泡立即发送一次，无确认、无缓存选择。纯文字创建新文本元素并调用 TIM 原生发送；其他类型使用原生转发路径。是否支持图片/语音/特殊卡片以实测为准。
- 机型伪装接入 TIM 的 UIDevice 分类、DeviceInfoUtil、QAnaDeviceUtil，并在 TIM 进程内覆盖 hw.machine 与 uname.machine 读取。内置 iPhone 12–16 系列名称/标识映射，例如 iPhone 15 Pro → iPhone16,1。任意自定义名称仅改显示文字。
- 删除闪照保存、截图回调拦截、图片预览和导出代码与设置。既有图片不自动删除。

## 使用

TrollFools 用户：移除 TIM 中所有旧 TIMCleanKit 注入项，只注入本版 TIMCleanKit.dylib。完全退出 TIM 后重新打开，再在任意区域双指长按 0.8 秒打开设置。

请勿同时安装 DEB 与 TrollFools 注入；二选一。RootHide 的 DEB 为 iphoneos-arm64e，Dopamine/rootless 的 DEB 为 iphoneos-arm64。

## 必须实测的项目

1. 设置能在聊天区域通过双指长按打开；背景有模糊、弹窗能关闭，关键词键盘与滚动正常。
2. 双击一条对方文字消息，核对原会话出现一条新发送文字；诊断 repeatRequests 增加。不要拿“请求计数”当成发送成功。
3. 新收到一条消息后让对方撤回，核对内容保留及“拦截撤回”标记。记录 recallEvents / recallBlocked / recallRestores / messageCellBinds / recordReadFailures。
4. 默认词命中的红包被跳过。未知金额放行开关和自行填写的金额范围按说明工作。
5. 机型名称和标识读取是否命中；已登录设备的服务器历史记录不保证更新。

1.0.4 自动抢红包已由用户确认生效。1.0.5 的改动仅完成静态 ABI 核验和 CI 编译；1.0.9 复读与红包逻辑简化，仍需**在用户手机上安装运行验证**。编译成功不等于运行成功。

缓存只在内存，不保存聊天文本；进程重启后丢失。不能恢复启动前或缓存之外已被删除的消息。Swift record 偏移后备读取严格校验本次 TIM 可执行文件 UUID，其他版本不套用此偏移。

自动领取沿用前台、两分钟内新消息、串行去重逻辑，后台或历史红包不保证领取。机型伪装仅作用于 TIM 进程，不修改真实硬件、系统版本、账号凭据或服务器历史。

如有闪退、黑屏或设置异常，请提供 CrashReporter 日志和“复制诊断摘要”；日志分析与手机核验保持只读，不自动安装、注销或重启。
