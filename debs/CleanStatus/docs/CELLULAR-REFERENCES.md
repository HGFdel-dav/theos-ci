# Cellular reference provenance

This candidate reimplements the requested behavior in CleanStatus's own source layout. It does not ship the uploaded vendor frontends, CCSIMTool binary, vendor reference trees, or uploaded icon artwork. New PNG artwork is generated by `tools/draw_cellular_icons.py`.

Behavior/API references (not proof of iOS15.5 runtime compatibility):

- SorenNing / Ning, SIMControl snapshot `4216d49e7c85c81fad663bfeef3f8d18945fa285`: https://github.com/SorenNing/SIMControl — the uploaded helper provenance also credits Netskao / ControlCenter18. The opaque index-based tool is NOT incorporated into this production source tree.
- SorenNing / Ning & Netskao, DataSwitch snapshot `301e2510b2448a8781e0c08496b76641afbb471c`: https://github.com/SorenNing/DataSwitch — reference for separate data-SIM selection, UUID identity, and the void setter contract.
- Frozen iOS15.3.1 runtime-header snapshot `44a5b62df41f5f20d8af6dead3b426a7b401e118`: https://github.com/yuzhouheike/iOS15.3.1-Runtime-Headers — CoreTelephony and CellularPlanManager method/category evidence, NOT the exact target device.
- Apple XNU `libsyscall/wrappers/libproc/libproc.h`: https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.h — original `proc_pidpath(int, void *, uint32_t)` declaration. Retrieved header is outside production source under `evidence/apple-libproc.h`.

Private MobileKeyBag lock-state and Darwin notification behavior are provisional compatibility gates, not a documented public API guarantee or a target-device observation. Neither references nor successful parsing establish entitlements, AMFI acceptance, native touch arbitration, or radio behavior on RootHide iOS15.5. Those remain explicit acceptance items.
