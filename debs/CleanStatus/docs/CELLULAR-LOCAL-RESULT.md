# CleanStatus 0.3.2 蜂窝功能：本地候选

日期：2026-11-21。状态：源码已补齐，本地可执行检查通过；不是已构建或已验收的发行版。

## 已确认且未改变的布局

1. 系统原有蜂窝数据按钮：轻点继续走原来的 ON/OFF；长按打开蜂窝管理，逐条启用或停用 SIM。
2. 只新增一个独立控制中心模块“数据切换”，轻点展开后选择默认上网 SIM。
3. 两个新功能默认关闭；旧状态栏、电池、动画、Wi-Fi/蓝牙列表和系统操作的行为源码不改。

## 本地实现

- `Cellular/` 是单独的 SpringBoard 注入库，未向旧主库的 Sources/Hooks 混入蜂窝代码。已识别原控件、原轻点动作、系统镜像、方法签名和锁状态才绑定长按；条件不明时保留原路径。实际手势仲裁仍须真机测试。
- SIM 线路由订阅 UUID 关联计划，再用计划 ICCID 核对唯一身份；不把数组序号当卡槽。启停工具只有可审查源码，不包含上传包的 CCSIMTool。停用任何一条线路都要确认。
- 数据切换使用经过签名核对的 void setter；无 NSError 或工具退出 0 仅代表未即时拒绝，不显示为成功。后续重新读取同一身份的系统状态才显示“已确认”。此处是计划/订阅状态读回，不是基带连通性测量。
- 打开、刷新、取消、收起、锁屏、功能关闭均有 token/generation 围栏；回调到主线程。已经发给系统的请求不能靠关闭界面撤回，超时文字不宣称已撤销。
- 运行端通过通知读取同一份隐根设置。保存先原子写入并逐字节读回；成功迁移也发通知；最终发请求前再读开关。迁移成功后不在每次保存时重新扫描旧根。
- 不记录号码、ICCID、UUID、原始异常或运营商账号；诊断仅受控原因码及卡槽，最多 128 条。
- 数据模块与注入库的共享 Objective-C 类均隔离命名；图标为本候选重新绘制的原创双卡图形，未分发上传图标。

## 两处 UI 的视频对齐纠正（2026-11-21）

用户指出之前只对齐了功能，没有对齐视频外观，明确要求数据模块和蜂窝点开两处都改。本轮已在本地把设置页式列表改成视频比例的紧凑圆角卡片：标准文字下宽 336、高 216、圆角 38，上方小图标与居中标题，下方两行运营商及绿／灰状态胶囊。蜂窝为“已开启／已关闭”，数据为“使用中／未选用”；未知状态不会变绿。

蜂窝弹层改为居中深色材质、点外部关闭；数据模块保留控制中心原生展开容器并使用相同紧凑尺寸。移除旧底部大面板、完成按钮、系统滑动开关和勾选列表。错误及重试内容仍保留，长内容可滚动，标题可点按刷新，支持 VoiceOver 关闭。停用确认、忙碌禁止重复操作、token/generation 及读回后才改变状态均保留。

`docs/CELLULAR-UI-VIDEO-PROTECTED.json` 保护本轮前的 119 个非 UI 文件，包括后台、身份校验、工具、设置及手势 hook，全部逐字节未改。`evidence/ui-video-alignment/` 保存前快照、视频参照、检查日志及标明非真机的 HTML 样式示意。浏览器示意仅核对比例和排版，不是 UIKit 截图，也不证明系统模糊、动画、手势或原生约束已真机通过。
