# CleanStatus 0.3.3：直接复用现有路径源码（本地候选）

日期：2026-11-21。授权来自用户“整个插件都是源码，之前怎么写就怎么写”的要求；仅本地修正，不含推送、CI、安装或设备配置修改。

## 做法

这次不再写一套隐根发现。插件原有 `Animation/LocalCleanStatusAnimationPreferences.m` 已有对数据根 `.jbroot` 反向链接的处理，新蜂窝版本之前漏用了这一层。

- 蜂窝代码直接调用原公开函数 `local_cleanstatus_animationPreferencesPath()`，在同一目录下换成独立的 `com.local.cleanstatus.cellular.plist` 文件名。原函数及其源码不改，不调用动画设置的读取、写入、迁移函数，不混用两份设置内容。
- 面板已经链接这份原文件；只给蜂窝注入库、数据切换模块和工具三个新增目标补上同一原文件及头文件接线。原主库和动画库目标定义、全部旧 Sources/Hooks/Shared/Animation/SystemActions 保持原样。C 符号继续以 hidden 方式链接，避免跨镜像抢用实现。
- 删除蜂窝重复的评分/发现代码。锁、原子写入、逐字节读回、迁移通知、回调及诊断逻辑都保留；同一路径由各端读取，不把真实 var 当独立写入目标。
- SIM 工具文件在同一旧解析器选中的根里查找：直接路径或该数据根现有的 `.jbroot` 反向链接，不再自行扫描/猜另一个根；工具的业务源码和权限不变。
- 版本仅在本地候选升为 0.3.3，区分用户已安装的 0.3.2。本轮没有 commit/push、GitHub Actions 调用、安装或设备操作。

## 明确保留

视频式两处卡片的代码、全部图标、原蜂窝短按/长按 hook、数据模块行为、订阅身份校验、停用确认、取消/token/readback 流程均逐字节不变。蜂窝存储代码从默认值到原工具路径函数之前的整个区段，以及限量诊断函数，另有固定哈希证明未被顺手改写。

## 测试不再绕过根发现

以前 Apple 存储夹具预先给出 selected root，绕过生产根发现。本轮已经删除这个分支：

- 临时编译单元使用完整且未改算法的原动画设置源码，只把文件系统的枚举父目录和 rootless 回退前缀指向临时夹具，**不注入选中的根、不替换评分/缓存/反向链接算法**。生产原文件字节不变，生产 Makefile 不带夹具宏。
- 原存储 roundtrip 测试改成真实的“程序目录＋数据目录＋反向链接”结构，数据根没有程序库也应能选中。
- 新增 split/flat、缺根、无证据根、根自身为链接、旧回退、目录逃逸、缓存后根消失及独立写进程/读进程等原生夹具；工具定位只检查文件，不执行它。
- 临时目录中的旧动画/主设置哨兵应保持原内容，证明不误写原配置。

## 证据与限制

本地主机可以运行便携 C/源码约束、完整旧功能检查和固定 iPhoneOS15.5 SDK `-fsyntax-only`；不生成 iOS 机器码。Apple Foundation 的实际存储/新目录夹具和假订阅执行在这里仍明确 SKIP，不能把源码解析通过当成原生测试通过。

最终命令、退出码、精确修改清单和文件哈希保存在候选外层 evidence/。还须用户另行批准推送，在 macOS CI 真正执行原生夹具、编译链接与出包验包；安装需再次单独批准。手机上的实际保存、通知生效和蜂窝行为尚未用本候选验证，不能说已经装机修好。
