# ParticleX 0.1.0dev3

作者 **Niubiprass** · 面向 **iPhone 12 / A14 / iOS 15.5 / RootHide**。

## dev3 本轮更新
- 清除按钮两种样式：通透磨砂「垃圾桶＋一键清除」文字胶囊、纯垃圾桶圆形。设置 → 清除按钮样式，立即生效。
- 圆形款优先读取锁屏手电筒/相机按钮的可见磨砂圆面尺寸并在同一排居中对齐，不改动系统按钮。若暂不可见/尚未布局则以 50pt 回退，下一次原生布局自动重新测量；宽度不足时避免挤压系统快捷按钮。
- 材质用真正的 UIVisualEffectView 超薄磨砂，不再是深色实心底。尊重「降低透明度」辅助功能设置，该选项开启时会使用更不透明的易读底色。
- 四档密度：省电（约1000消散粒子、控制中心20%发射率）、标准（约6000、100%）、细腻（约12000、185%，粒径更细）、密集（约16000、250%）。消散数量按视图比例生成网格会略少于目标；标准保持 dev2 参数。
- 仅变更按钮外观/布局与粒子密度参数，原生通知清除、亮度音量数值与 App 归类算法未改。

## 功能
- 通知清除时：原通知内容采样，细粒子逐渐消散。
- 移除桌面小组件时：对当前被移除的小组件作原色消散。
- 控制中心：正常拖动系统亮度/音量等连续滑条时，粒子沿原滑条填充边缘流动。**没有悬浮亮度条，不修改亮度/音量或控制中心布局。**
- 通知和小组件分别选择：左→右、右→左、上→下、下→上、随机方向（每次效果选定一个方向）。
- 通知列表底部「一键清除」：调用系统当前/历史/错过通知区的原生清除操作，不只是隐藏视图。可单独关闭按钮。
- 「通知按 App 归类」为可选测试功能：同 App 的不同对话归入同一原生通知组，保留真实通知对象。默认关闭，开启/关闭后要重新载入 SpringBoard；不会立即迁移正在显示的旧分组。
- 系统设置 → ParticleX：总开关、三个场景独立开关、消散时长、粒子密度、方向、归类、一键清除、诊断日志。

## 安装注意
本项目本地编写、GitHub macOS CI 使用 **iPhoneOS15.5.sdk** 构建。作者不会自动安装、注销或重启你的手机。

选择 `iphoneos-arm64e.deb` 用于 RootHide。`iphoneos-arm64.deb` 是普通 rootless 路径版，不要混装。两个包都包含 arm64 和 arm64e 机器码切片，但包路径/架构元数据不同。

安装更新需要按包管理器提示重新载入 SpringBoard；动画开关/参数可热更新。按 App 归类策略为避免已有分组索引错配，锁定到本次 SpringBoard 会话，变更归类或总开关影响归类时需重新载入 SpringBoard。不要在启用其他通知分类/堆叠插件时同时测试归类。若使用 Choicy 白名单/RootHide 注入管理，需允许 ParticleX 注入 SpringBoard。

## 首轮验收清单（尚需真机验证）
1. 在锁屏/通知中心清一条通知；确认通知确实清除，有原色粒子。
2. 清一组/全部通知；确认不是只消散背景，不残留通知。
3. 添加一个临时小组件 → 移除 → 确认；只有移除确认后出现粒子。取消移除不应播放。
4. 控制中心拖亮度、音量：原生数值正常变化，粒子只出现在控件内部，不挡手势。
5. 总开关关闭后重测；不应出现任何 ParticleX 动画，原生功能不变。
6. 开「辅助功能 → 动态效果 → 减弱动态效果」后不应播放。
7. 切横屏、退出控制中心、锁屏再解锁；不残留透明触摸层或粒子。

## 安全与诊断
只注入 SpringBoard；局部视图快照只存在内存里，不存图片、不记录通知文字、不采集账号/网络数据。GPU 粒子数量、并发、纹理大小和日志大小都有上限。减少动态效果时停用。

Hook 安装/ABI 不符会记入日志，可在设置页「查看诊断日志」复制。RootHide 日志位于当前活动隐根的 `var/mobile/Library/Logs/ParticleX/runtime.log`，由 libroothide 解析，不硬编码 UUID。

如出现 SpringBoard 崩溃/安全模式：在安全模式里卸载 ParticleX，或关闭对 SpringBoard 的该插件注入，再重新载入。请提供对应 SpringBoard `.ips` 与 ParticleX 日志，不要反复全机重启。
