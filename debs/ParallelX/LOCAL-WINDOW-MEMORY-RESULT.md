# ParallelX clone0.93 窗口大小与位置记忆：本地结果

## 已完成的本地实现
- 每个 App 按 bundle 单独记忆普通浮窗的大小和位置；同一 App 的 Crane 账号共用。设备方向、内容方向组合隔离，横竖屏不串。
- 使用原版 PXHostCard，不重造窗口；手势正常结束后保存；新建普通/分身浮窗时读回并恢复。取消、全屏交接、键盘临时布局、角落小窗不会写成正常大小。
- 默认开启；原设置“分屏窗口与角落小窗”旁新增“窗口大小与位置记忆”页面，包括记忆开关、确认清空、诊断开关与存储状态。
- 清空不动当前窗口、不动账号；下次新建用默认大小。关闭不删除已存数据。写入有跨进程锁、原子替换和完整读回，清空/关闭使过期保存任务失效。
- 所有磁盘操作在后台；新模块不发开窗/切号/杀进程请求，不改付款、通知路由、现有账号流程。接入失败不阻止原版开窗。
- 独立记录保存、回读、通知、运行端接收、恢复实际几何和后续布局读回；256 条限量，可关闭；只含匿名 App 标记、数字与状态，不含账号、聊天、URL、凭据。

## 已验证
- 本地 unittest：156 项，147 项执行通过；9 项 Apple Foundation 原生存储测试因 iSH 没有 Apple 运行时跳过，明确不算通过。
- 生产 C 几何/时序规则：4364 项断言通过；4 个故意破坏边界、清空代次、迟到恢复与旋转隔离的编译负例被真实 harness 拒绝。
- 原版 6 个真实方法表条目的 selector、编码及 IMP 与 fixture 逐字节匹配。
- 固定原版 DEB hash 和 vendor 16 文件逐字节保护通过；原有 140 项回归全部通过。
- 项目 validate：plist、两 scheme 维护脚本/版本生成、结构检查、未使用声明检查和全部 host tests 通过。
- Apple 存储测试已经加入现有 unittest 入口；授权后 GitHub macOS CI 会实际编译/运行生产存储，禁止在 Apple runner 缺 xcrun 时静默跳过。
- 最终 DEB 验证器新增记忆页面入口与两个镜像的功能标记检查；目前没有新 DEB，不写为已验包。

## 明确未验证
- 未进行任何本地 iOS 插件编译；没有新 CI、签名产物、安装或真机功能验收。
- UIKit 挂接、普通打开/分身切号后实际可见尺寸、原生后续布局是否保留恢复尺寸、键盘/横屏/停靠相邻行为，必须由 iOS 构建与独立获准的真机验收闭合。几何日志不等于像素/黑屏证明。
- 当前 0.92 的稳定反馈不代表这些新路径已验证；新版本只称“本地候选完成”。
